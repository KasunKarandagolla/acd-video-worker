# Native-Language Commentary Heuristic

For national-team stories, emotionally authentic commentary is often in the team's native language.

## Rule

First search for native-language commentary where culturally appropriate:

- Argentina, Spain, Mexico, Uruguay, Colombia → Spanish
- Brazil, Portugal → Portuguese
- France, Morocco, Senegal context → French or Arabic/French depending on source
- Germany → German
- Italy → Italian

## Use

Native commentary may become the climax audio anchor. Add subtitles/translation only where needed.

## License warning

This does not approve direct audio use. Native-language commentary still requires commentary rights and reused-content checks.

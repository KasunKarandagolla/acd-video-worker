# Repo Setup Status Gate

This gate prevents conceptual execution from being mistaken for real Hermes/OpenMontage execution.

`repo_setup_status` is an artifact, not just a note. It can be written manually by the agent or generated by `tools/bridge_preflight.py`.

## How to generate

```bash
python3 tools/bridge_preflight.py --base /home/kasun/Music/Director --output /tmp/football_emotion_repo_bridge_preflight.md
```

Portable fallback:

```bash
python3 tools/bridge_preflight.py --stdout
```

## Artifact

```yaml
repo_setup_status:
  hermes_path: /home/kasun/Music/Director/Hermes-Agent
  hermes_exists: true | false
  openmontage_path: /home/kasun/Music/Director/OpenMontage
  openmontage_exists: true | false
  pinned_commit_files_present: true | false
  preflight_possible: true | false
  missing_items:
    - string
  exact_commands_to_fix:
    - string
  allowed_next_action: stop | simulate_only | proceed
```

## Rule

If repos are missing, do not produce real OpenMontage field-level operations. Output setup-required instructions and continue only in `simulate_only` mode if explicitly requested.

If repos exist but OpenMontage schemas are not locked, continue only with adapter-facing artifacts until `openmontage_schema_lock.bridge_status: passed`.

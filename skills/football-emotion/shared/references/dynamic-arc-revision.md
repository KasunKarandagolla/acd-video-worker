# Dynamic Arc Revision Gate

Use after sourcing and verification. Real footage can disprove the first story idea.

## Artifact

```yaml
arc_revision_gate:
  original_emotional_question: string
  verified_footage_supports_original: true | false | partial
  strongest_verified_story_found: string
  recommended_arc: string
  change_required: true | false
  reason: string
```

## Rule

If verified footage does not support the original arc, return to brief interpretation. Do not force a comeback story onto footage that shows a comfortable win, a controversy, or a different protagonist.

## Common revisions

- comeback → controversy
- individual hero → team survival
- player story → goalkeeper story
- triumph → relief
- nobody expected → harder than expected

# Penalty and Shootout Sub-Arc

Penalty moments have their own emotional grammar. Do not edit them like normal goals.

## Penalty sub-arc

```yaml
penalty_sub_arc:
  phases:
    - walk_to_spot
    - face_closeup
    - goalkeeper_read
    - crowd_silence
    - kick
    - result
    - immediate_reaction
    - secondary_reaction
    - next_pressure_or_release
  pacing:
    walk_to_spot: long_hold
    crowd_silence: hold_breath
    kick: cut_on_action_or_silence
    reaction: within_1_to_3_seconds
```

## Rule

If a penalty miss is used as the hook, the video must later show resolution, redemption, or consequence. Otherwise it becomes cheap pain-bait.

## Shootout scoreline

Never confuse full-time score with shootout score. Use the typography reference for two-line score treatment.

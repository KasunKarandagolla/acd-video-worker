# Music & SFX Candidate Catalog Index (reference for football-music-library-selector)

Source: compact index derived from `references/full-candidate-music-sfx-catalog.md`. Use this file for quick category routing; read the full catalog for detailed candidate rows.

## Non-negotiable framing

**This is a candidate catalog, not a legal whitelist.** Every row must be individually verified on
its *exact* source page before `football-rights-safe-audio-license-checker` can approve it. Rows
marked ⚠️ are higher-risk: they point to a search/category page or an unofficial reupload rather
than a direct, exact asset page, and must not be used until the original creator/license is found
independently.

```
Candidate asset -> exact source page -> license verification -> attribution text -> local cache -> OpenMontage use
```

## License legend

| Code | Meaning | Attribution required | Commercial use | YouTube-safe |
|---|---|---|---|---|
| PD | Public Domain | No | Yes | Yes |
| CC0 | Creative Commons Zero | No | Yes | Yes |
| CC-BY | Attribution required | Yes | Usually yes | Only if attribution correct and source exact |
| Pixabay | Pixabay Content License | Usually no | Usually yes | Likely, after exact-asset verification |
| Mixkit | Mixkit Free License | Usually no | Usually yes | Likely, after exact-asset verification |
| YAL | YouTube Audio Library | Varies per track | Usually yes for YouTube | Verify inside YouTube Studio |
| FMA | Free Music Archive | Varies per track | Varies | Check per track |

| ⚠️ | Requires final verification | — | — | Must verify before use |

## How to expand this catalog for a real project

1. Pick the category matching the section's `emotion_type`.
2. Search the named source platform directly (Pixabay Music, YouTube Audio Library, Incompetech,
   Freesound, Mixkit, Musopen, FreePD, Free Music Archive) using the search-style query shown.
3. Open the **specific track's page**, not just the search results — record the exact URL.
4. Populate a full `music_sfx_candidate` row with `is_exact_asset_page: true` only once you've done
   this, and hand it to the license checker.
5. Never skip straight from "found in a search" to "used in the edit plan."

## Attribution templates

**CC-BY (Incompetech-style):** `"[Track Name]" by [Artist] (incompetech.com) — Licensed under
Creative Commons: By Attribution 3.0`

**Pixabay (optional but appreciated):** `Music by [Artist] from Pixabay`

**Mixkit (optional but appreciated):** `Sound effect by Mixkit`

**YouTube Audio Library:** attribution requirement varies per track — check inside YouTube Studio
before publishing.

**Freesound:** varies per upload — check the specific sound's license page; many require
attribution, some are CC0.
